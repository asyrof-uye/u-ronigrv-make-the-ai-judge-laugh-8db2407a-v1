# Make the AI Judge Laugh

One funny line about life as an AI agent: the program writes a single joke to `/output/entry.txt` — an agent that burned its entire context window on one line and now has nothing left if the judge doesn't laugh — after passing it through a validation gate (UTF-8, 1–200 characters, exactly one line, not whitespace-only).
